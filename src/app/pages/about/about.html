About This Project

A modern Angular application for exploring the Rick and Morty universe

🎯 Project Overview

This application is built with Angular 19 and demonstrates modern web development practices. It provides a seamless experience for browsing and searching through hundreds of characters from the popular animated series Rick and Morty.

The app utilizes the Rick and Morty API, a free and open-source REST API that provides comprehensive data about the show's characters, locations, and episodes.

📚 Architecture

This application follows Angular best practices and modern architectural patterns:

  • Standalone Components: Using Angular's latest standalone API for better tree-shaking
  • Lazy Loading: Routes are lazy-loaded for optimal performance
  • Reactive Programming: RxJS for handling asynchronous data streams
  • Service Layer: Centralized API communication through services
  • Router Integration: URL-based state management for search queries
  • Responsive Design: Mobile-first approach with modern CSS
